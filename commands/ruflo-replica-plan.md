Create a clean-room feature-parity plan for:

$ARGUMENTS

Use only public, authorized material and the user's own authorized account. Do not inspect proprietary source code, private APIs, network traffic intended to reproduce an undocumented API, paywalled content, credentials, or another user's account.

Deliver:

1. an evidence-linked feature and flow map;
2. an explicit in-scope / out-of-scope boundary, including brand, copy, assets, licensed data, integrations, and network effects;
3. a fresh architecture and implementation order;
4. a testable parity matrix with must/should/could/omitted status;
5. a new name, copy, and visual identity plan;
6. a realistic effort, risk, and compatibility estimate.

Do not claim perfect or 100% parity. State what evidence would be needed to measure the target scope.
